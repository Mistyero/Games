# Games
Single File games for people at school
#### Will add more games as I find/create them
## Click [Here](https://github.com/Mistyero/Games/releases) for game downloads.
### Find the game you want, then click on Assets to expand them (if not already), then download the game file (ignore source code files), then open the file to load the game.

## To play any of these you will need to go to [htmlhoster](htmlhoster.com), click upload file and choose you game file, then click upload, then once it finishes uploading click open in new tab.

## If you find any issues/bugs with the files you can click issues at the top and report it.
